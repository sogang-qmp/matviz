## What shipped

`web/structure-viewer-matviz.html` — a recipe HTML fragment in the
`sogang-qmp/recipes` house style, demonstrating the matviz embed. Staged in this
repo; final home is the recipes repo (and the `112-Gd2C-H/site` as a copy).

### House-style conformance

- `<!--meta ...-->` block (title / updated / tags / summary), Korean-first.
- **Fragment only** — no `<html>/<head>/<body>`.
- Section order: intro (1-line + bullets) → `Live demo` → `데이터 형식` →
  `복사해서 쓰기` (`<pre><code>` HTML-escaped).
- Korean 개조식; `<strong>` on keywords only.
- Live demo `<script src>` points at the built bundle for local preview
  (`../dist/matviz-embed.js`); the copy-source block documents the real deploy
  paths — portal `/static/lib/…`, project site `assets/lib/…` (depth `../`).
- Inline data via `<script type="text/plain" id="nacl-data">` (NaCl CIF), one
  `MatViz.mount("nacl", { format:"cif", theme:"auto" })` call.
- Container ids namespaced by prefix; note that `prefix` must be page-unique.
- Positions the recipe as the *advanced* companion to the existing 3Dmol
  `structure-viewer.html` (iso / polyhedra / measurement / theme-following),
  per the kickoff "separate recipe" decision.

## Download / install (added 2026-07-22, user request)

Site authors should be able to *download* `matviz-embed.js`, not build it from
source. Since `dist/` is gitignored, the build now also copies the bundle to the
**tracked** path `web/matviz-embed.js` (esbuild.mjs, after the embed build).
esbuild's minified output is deterministic, so this only shows a git diff when
the bundle actually changes — no per-build churn, no staleness.

- Download URL (live after commit+push): `https://raw.githubusercontent.com/sogang-qmp/matviz/main/web/matviz-embed.js`
- The recipe gained a **다운로드 · 설치** section: download → drop into
  `assets/lib/` (site) / `static/lib/` (portal) → `<script src>` once. Mirrors
  how the site vendors `3Dmol-min.js`.
- Fixed the live-demo `<script src>` from the local `../dist/...` placeholder to
  the house-correct portal path `/static/lib/matviz-embed.js`. Re-verified the
  recipe renders (NaCl `Fm-3m`) via a portal-shell wrapper that rewrites the path
  to the sibling bundle; 0 errors.
