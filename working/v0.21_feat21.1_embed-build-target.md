# v0.21 feat 21.1 — Embed build target (+ render core, minimal theme)

**Date**: 2026-07-22
**Status**: complete, verified. First feature of v0.21 → check-in point (autonomous
limit is 1 for a version's first feature).

## What shipped

A self-contained embeddable widget bundle, `dist/matviz-embed.js` (665 KB
minified, Three.js + parsers + renderer), exposing `window.MatViz`. Renders a
crystal structure into a page element from **inline** data — no VSCode, no
extension host, no network, `file://`-safe.

### Files

- `src/webview/embed/index.ts` — the embed entry. `MatViz.mount(prefix, opts)`:
  reads inline text from `opts.data` or `#{prefix}-data`, parses **in-page** via
  `parseStructureFileTraj`, injects a canvas into `#{prefix}-viewer`, drives
  `CrystalRenderer` directly (which self-wires orbit/zoom/pick + resize).
  Handles `loadTrajectory` + `loadVolumetric`/`setIsoLevel`, `supercell`,
  `style`. `MatViz.setTheme(prefix, mode)` + instance `dispose()`.
- `src/shared/spglibWasm.embed.ts` — no-WASM stub (feat 21.6, done early because
  bundling `parsers/index.ts` drags the real module in). `isSpglibReady()→false`
  so `withSymmetry()` passes structures through (CIF group / P1).
- `esbuild.mjs` — third entry `embedConfig` (IIFE, minify) + `spglibEmbedStub`
  resolve-plugin that redirects `shared/spglibWasm` → the stub for the embed
  build only. `npm run build` now emits all four browser/node bundles incl.
  `matviz-embed.js`.
- `web/embed-test.html` — smoke-test host page simulating the
  `112-Gd2C-H/site` shell (`<html data-theme>` → `--bg` var + ◐ toggle).

## Theme (minimal 21.5, landed with the core)

`theme:"auto"` (default) resolves from `<html data-theme>` (the site shell's
exact signal, verified in `site/assets/site.js`) then `prefers-color-scheme`,
and reacts live via a `MutationObserver` on `data-theme` + a `matchMedia`
listener → `renderer.setColorPalette()` + `updateTheme()`. The canvas background
already tracks the page `body` background (renderer's `getBackgroundColor()`
reads `getComputedStyle(document.body).backgroundColor`), so the widget blends
into the page card in both themes with no extra work. `theme:"light"|"dark"`
pins it.
