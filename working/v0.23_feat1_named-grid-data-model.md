# v0.23.1 — Named-grid data model (pure refactor) — completion log

**Status**: ✅ complete. Gate v0.23-A passed.
**Date**: 2026-07-22.

## What shipped

Promoted the volumetric pipeline from single-grid to an array-capable
named-grid model, end to end, while every parser still emits exactly one
grid → rendering byte-identical to v0.22.1.

### Changes
- `src/parsers/types.ts` — `VolumetricData` gains optional `name?: string`
  and `kind?: 'scalar' | 'signed'` (additive).
- `src/parsers/index.ts` — `ParseResult` / `ParseTrajectoryResult` gain
  `volumetrics?: VolumetricData[]`; `volumetric` kept as back-compat alias
  (`=== volumetrics[0]`). New `attachGridList()` helper wraps a single
  grid into a length-1 named list (name `charge` for CHGCAR-family, else
  `density`; `kind` defaults `scalar`). Applied in `parseStructureFile`,
  `parseStructureFileTraj`, `parseStructureFileTrajFromBytes`.
- `src/webview/message.ts` — new `loadVolumetrics` (array) + `setActiveGrid`
  messages; legacy `loadVolumetric` retained.
- `src/editor/crystalEditorProvider.ts` — `ParsedContent.volumetrics`;
  posts `loadVolumetrics` with the full list (per-grid zero-copy
  `Float32Array` transfer preserved).
- `src/webview/main.ts` — `loadVolumetrics` + `setActiveGrid` cases; the
  stride-pill + iso-panel wiring extracted into shared `applyVolumetricUi()`.
- `src/webview/renderer.ts` — storage is now `volumetricGrids: VolumetricData[]`
  + `activeGridIndex`; **`volumetricData` is a private getter** over the
  active grid, so all existing read sites are unchanged. New
  `loadVolumetrics()`, `setActiveGrid()`, `getGridNames()`,
  `getActiveGridIndex()`, `refreshIsoForActiveGrid()`.

### The key invariant
Single-grid load → `volumetricGrids = [grid]`, `activeGridIndex = 0`, so
`volumetricData` getter returns the identical grid `buildIsosurface`
always meshed. Byte-identity is structural, not coincidental.
