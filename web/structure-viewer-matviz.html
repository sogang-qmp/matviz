결정구조를 matviz(Three.js 엔진)로 페이지에 삽입하는 뷰어이다. 기존 3Dmol 레시피보다 무겁지만 — 아이소서피스(전하밀도·파동함수)·배위다면체·거리/각도 측정·슈퍼셀을 지원하고, 무엇보다 페이지의 라이트/다크 테마를 자동 추종한다(3Dmol 임베드는 흰 배경 고정).

  • 입력: CIF·POSCAR/CONTCAR·XSF(벡터 포함)·Gaussian cube·CHGCAR — 인라인 <script type="text/plain">.
  • 테마: theme:"auto" — <html data-theme> + OS 설정을 관찰해 실시간 전환. 캔버스 배경은 페이지 배경색에 맞춰짐.
  • UI: 페이지-내부 그림답게 컨트롤 접힘이 기본. 우상단 ⋯로 펼침(스타일·슈퍼셀·아이소·리셋), Esc/바깥클릭으로 접힘.
  • 오프라인: 네트워크 fetch 없음(file:// 동작). 대칭성 검출(spglib)은 임베드에서 생략 — CIF 선언 space group만 표시, 그 외 P1.

다운로드 · 설치

  • 엔진 파일: matviz-embed.js — 약 660 KB, self-contained(Three.js·파서·렌더러 포함, 외부 의존성·네트워크 0).
  • 받기: matviz-embed.js 다운로드 (matviz 저장소 web/matviz-embed.js — 빌드 시 자동 갱신되는 배포본). 3Dmol-min.js처럼 self-host한다(CDN 없음).
  • 두기: 프로젝트 사이트는 assets/lib/matviz-embed.js, 포탈은 static/lib/matviz-embed.js(다른 vendored 라이브러리와 같은 위치). 갱신 시 파일만 교체.
  • 불러오기: 페이지에 <script src="…/matviz-embed.js">를 한 번(깊이만큼 ../) → window.MatViz 사용 가능.

Live demo

예제 NaCl(Fm-3m). 드래그 회전 · 휠 줌 · 우클릭 평행이동. 우상단 ⋯로 컨트롤. 페이지 우상단 ◐로 테마를 바꾸면 뷰어도 따라 바뀐다.

자기구조 예제 — NiO 반강자성. POSCAR MAGMOM 라인에서 모멘트 화살표(Ni↑ / Ni↓)를 자동 표시한다. ⋯의 Moments로 켜고/끄고, Arrows에서 Red–blue(부호색) ↔ Single(단일색) 전환.

데이터 형식

  • 구조 텍스트를 <script type="text/plain" id="{prefix}-data">에 그대로 인라인(원자 좌표·격자 포함).
  • 포맷은 format으로 지정(cif/poscar/xsf/cube/chgcar) 또는 내용 자동 감지.
  • 아이소서피스: cube/CHGCAR/XSF 볼류메트릭이면 iso: <level>로 등가면. 접힌 패널의 슬라이더로 조절.
  • 벡터(자기모멘트·힘): POSCAR MAGMOM·XSF 후행열·ext-XYZ·CIF moment를 화살표로 자동 표시. vectors:false로 끄기, 패널 Arrows에서 Red–blue/Single 색.
  • 옵션: supercell:[2,2,2], style:"space-filling", collapsed:false(펼친 채 시작), theme:"light"|"dark"(고정).

복사해서 쓰기

엔진 스크립트는 페이지에 한 번만. 그림 하나는 div + 데이터 블록 + MatViz.mount 한 줄. 구조를 바꿀 땐 데이터 블록의 문자열만 갈아끼운다.

1) 엔진 (페이지에 한 번)

<!-- 프로젝트 사이트: 깊이만큼 ../ (depth-2 페이지면 ../../assets/lib/) -->
<script src="assets/lib/matviz-embed.js"></script>

2) 그림 (구조마다 복사, 데이터만 교체)

<div id="myxtal-viewer" style="position:relative;width:100%;max-width:680px;height:440px;
     border:1px solid var(--border,rgba(128,128,128,.3));border-radius:6px;overflow:hidden"></div>
<script type="text/plain" id="myxtal-data">
... CIF / POSCAR / XSF 텍스트를 그대로 ...
</script>
<script>
  MatViz.mount("myxtal", { format: "cif", theme: "auto" });
  // 볼류메트릭이면:  MatViz.mount("myxtal", { format:"cube", theme:"auto", iso:0.02 });
</script>

prefix("myxtal")는 페이지에서 유일해야 한다(여러 그림 공존 시 id 충돌 방지). 테마 토글이 <html data-theme>가 아니면 themeAttribute/themeTarget으로 지정.
